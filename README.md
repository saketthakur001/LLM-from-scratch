# LLM from scratch

A small GPT-style decoder-only transformer, implemented from scratch in plain PyTorch
(no `transformers` model classes) — tokenizer training, dataset chunking, model,
training loop, and sampling.

## Layout

- `llm/tokenizer.py` — trains/loads a byte-level BPE tokenizer, encodes raw text files.
- `llm/dataset.py` — turns a flat token-id stream into fixed-length `(input, target)` chunks.
- `llm/model.py` — the model itself: token + positional embeddings, causal self-attention,
  feed-forward blocks, pre-LN transformer blocks, weight-tied LM head, autoregressive
  `generate()`.
- `llm/config.py` — `GPTConfig` (model size) and `TrainConfig` (optimization) dataclasses.
- `llm/prepare_data.py` — CLI: raw `.txt` files → trained tokenizer → `tokenized_texts.json`.
- `llm/train.py` — full training loop (AdamW, cosine LR with warmup, grad clipping,
  periodic eval + checkpointing).
- `llm/generate.py` — CLI: load a checkpoint and sample text from a prompt.

## Status

Architecture and pipeline are complete end-to-end. **Training has not been run** —
this was developed on a machine without a GPU, and a from-scratch LM needs far more
than CPU time allows to produce coherent output. Everything is wired up and ready to
run as soon as GPU compute is available.

## Usage

```bash
pip install -r requirements.txt

# 1. put raw .txt training files under txt/
python -m llm.prepare_data --txt_dir txt --vocab_size 20000

# 2. train (edit llm/config.py first — set TrainConfig.device = "cuda")
python -m llm.train

# 3. sample from a checkpoint
python -m llm.generate --prompt "Once upon a time"
```

## Notes

- `hermes-vocab.json` / `hermes-merges.txt` are tokenizer artifacts, regenerated by
  `prepare_data.py` — not meant to be hand-edited or treated as source.
- `TrainConfig.device` defaults to `"cpu"` as a safety default; it will run but is
  not a realistic way to train this model to convergence.
